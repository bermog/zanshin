# Source: design-system reference, layout blocks

What it is: page 16 of the reference course series on design systems (CC BY-SA 4.0). Page last modified 2026-10-24; filed in [raw/design-system-reference-layout.md](raw/design-system-reference-layout.md) on 2026-11-14.

Statements that matter for the project:

1. A layout block (`l-`) always has two kinds of element: the parent (the block) and its children, called areas, with classes `__area` or `__area-<name>`.
2. A layout's CSS only changes the position, and sometimes the size, of its areas. It never sets colours, fonts or other visual properties.
3. The area class on a child is optional when it serves no purpose.
4. An area may hold a component (the component may carry the area class itself) or another layout block.
5. Reference layouts: `l-flex` (flex with direction and justify modifiers and an area `--grow2` modifier), `l-columns` (grid with `--1` to `--12` modifiers generated by a loop and an area `--span2` modifier), `l-extremo` (two areas pushed apart with auto margins).
6. Not covered: breakpoints, tokens, globals, padding or gap.
